# Amphoreus · 永恒之地翁法罗斯

一个**不可操控**的世界。你只能看。

翁法罗斯是《崩坏：星穹铁道》里由「帝皇权杖 δ-me13」运行的模拟世界。这个项目把它按设定重新实现了一遍：十二位泰坦、十三位黄金裔、十二枚火种、一座正在被黑潮吞掉的星球，全部由代码演算。

打开网页，看它自己走。你不参与。

---

## 这是什么

- **一个模拟，不是一个游戏。** 没有操作、没有存档、没有结局。世界按光历自己往前推，一拍一个时段。
- **每个人都得到不同的结果。** 世界由种子决定因果：同一个种子永远走出同一段历史，换一个种子，就是另一个翁法罗斯。
- **写自己的书。** 演算到一定进度，它会用「如我所书」的笔法把发生过的事记下来——十三卷，每卷五节。
- **零依赖。** 只用 Python 3.13 标准库。不装任何第三方包。

## 快速开始

```bash
cd Amphoreus
python3 main.py start
```

然后打开 <http://127.0.0.1:8760/>。

第一次启动会随机生成一个种子，并写出一份 `config.toml`。想固定这个世界的因果，把 `seed` 填成当时的数字即可。

### 常用命令

| 命令 | 作用 |
|---|---|
| `python3 main.py start` | 前台运行，Ctrl-C 停止 |
| `python3 main.py daemon` | 后台挂机，关掉终端也继续跑 |
| `python3 main.py stop` | 停掉后台进程 |
| `python3 main.py status` | 看现在跑到哪一年、火种收了几枚 |
| `python3 main.py install` | 装成 launchd 开机自启（macOS） |
| `python3 main.py uninstall` | 卸掉开机自启 |
| `python3 main.py once 300` | 只推进 300 拍然后退出，用于验证 |
| `python3 main.py reset` | 清空当前世界（需输入 yes 确认） |

## 如我所书

<http://127.0.0.1:8760/book> 是独立的一本电子书，和仪表盘分开。

它照游戏里那六件档案的结构做：

| 档案 | 里面是什么 |
|---|---|
| 翁法罗斯英雄纪.exe | 十三卷正传，每卷五节。节名照官方原文录入，正文由这个世界的演算生成 |
| 逐火者的命路.exe | 十三位黄金裔各一首四行长诗，官方原文 |
| 迷迷.exe | 记忆里的小女孩记得的十二件事 |
| 管理员批注.wav | 三十四行以 `>>>` 起头的独白，无署名，无应答 |
| δ-me13.exe | 演算的八个阶段，从无机到结论 |
| 邮箱.exe | 官方那十一则「自旅途间……前往书中将其写下」的书写指引 |

书是**只读**的。你不能在里面改任何东西，就像你不能改这个世界。

配色照官方复刻界面的 CSS 取值（强调金 `#c1ad7d`、面板底 `#282828`、浅书页 `#e9e3db`），不是截图取色。次要文字的颜色是自己定的，取到过 WCAG AA 4.5:1 为止，`tools/selftest.py` 会验算对比度。

## 它是怎么演算的

世界状态就是一组数：每座城的人口、秩序、信仰、黑潮水位，每位泰坦的存活与神性，每位黄金裔取火种的进度。

每一拍（= 光历的一个时段）：

1. 用 `seed × 1000003 + cycle × 9176 + tick × 7919` 算出这一拍的随机源。种子固定，历史就固定。
2. 各城邦的指标朝平衡点**松弛**过去，而不是随机加减——这样人口不会归零，黑潮也不会一路顶到 1.0。
3. 判定这一拍有没有事发生：夺火、城邦陷落、泰坦陨落、再创世。
4. 十二枚火种集齐后，δ-me13 推进一个阶段；全部走完就再创世，轮次 +1，重来。

再创世不是重置。种子不变，但 cycle 变了，随机源随之改变，所以第二轮的历史和第一轮不一样。

## 节奏

默认是 **1:1**：现实过一秒，世界过一秒。

一个时段 = 现实 4.8 小时。所以默认配置下，**要让世界过完一天，现实里也要过一天**。这是刻意的——想看它慢慢烂掉，就得真的等。

想快进就改 `config.toml`：

```toml
[pace]
mode = "accelerated"
world_days_per_real_second = 1.0   # 现实每秒推进一个世界日
lock_speed = false                 # 顺便在网页上放出调速控件
```

## 叙事层

规则引擎负责「发生了什么」，本地模型只负责「怎么讲」。

默认接本地 Ollama（`http://127.0.0.1:11434`），模型 `qwen3.5:4b`。**模型不在也没关系**：连不上就自动降级成模板文本，模拟一秒都不会停。

模型输出会过一道硬校验——含阿拉伯数字、泄漏百分比/进度这类演算读数、一逗到底、夹英文，一律打回重写一次，仍不合格才用模板。这道校验是必须的：实测小模型很爱把「试炼完成度约 70%」直接写进碑文里。

## 数据

一切都在 `data/world.db`（SQLite）。六张表：

- `meta` — 种子、当前 tick、演算轮次、黑潮与方程式进度
- `cities` — 十处地方的秩序、信仰、侵蚀
- `titans` — 十二位泰坦是否已被夺火
- `scions` — 十三位黄金裔的试炼进度
- `events` — 流水账，逐拍记录
- `ledger` — 如我所书，按卷归档

断点续跑靠 `tick`。停机期间欠下的时间会按锚点补算回来，所以挂机是连续的。

## 设定依据

世界观不是编的。`amphoreus/canon.py` 里每一条都标了出处与置信度：

- `confidence: "canon"` — 有官方原文
- `confidence: "design"` — 本作设定（例如各城邦的初始人口与侵蚀值）

主要来源是 [BWIKI 翁法罗斯条目](https://wiki.biligame.com/sr/翁法罗斯) 及其子页面（`δ-me13.exe`、`翁法罗斯英雄纪.exe`、`逐火者的命路.exe`、`管理员批注.wav`）的原始 wikitext。历法、十二泰坦分组、十三黄金裔的命途与原动力、δ-me13 的八阶段进度值，都照原文录入。

已知取舍：

- **六十万年前的地理**没有官方地图。`web/app.js` 里的星图是按城邦相对方位画的示意图，不是投影地图。
- **各城邦初始人口**是设定，不是官方数据。定性判断（大部分城邦半毁、唯奥赫玛因黎明机器维持）来自官方。
- **B 站没有开放按全站播放量排序的接口**，所以本项目没有引用「播放量前十」之类的榜单数据，只用官方设定。

## 原则

- **只读观看。** 网页端没有任何写入口，不是靠自觉，是靠架构。
- **不臆造。** 设定有出处的标 canon，没出处的标 design，两者不混。
- **零依赖。** 不为了省几行代码引一个包。
